# Alan Mosely

I maintain open-source tools for Flutter networking, ESP32 provisioning, Jira
development workflows and personal claims archives.

- [esp_provisioning_wifi](https://github.com/alanmosely/esp_provisioning_wifi) — ESP32 Wi-Fi provisioning over Bluetooth LE from Flutter.
- [mdns_bloc](https://github.com/alanmosely/mdns_bloc) — mDNS service discovery with a Dart BLoC API.
- [daggerverse](https://github.com/alanmosely/daggerverse) — ESP-IDF and ESP-ADF build modules.
- [TEAtime Starter](https://github.com/alanmosely/teatime-starter) — an Eleventy and Tailwind website starter.
- [Basic Jira Development Panels](https://github.com/alanmosely/basic-jira-development-panels) and [Jira Watcher Field](https://github.com/alanmosely/jira-watcher-field-plugin) — Jira plugins.
- [BUPA SCUPA](https://github.com/alanmosely/bupa-scupa) — a local claims utility and personal archive.
